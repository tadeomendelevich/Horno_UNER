Control de potencia y menu

El slider actua directo sobre `power`; el D-pad navega el menu remoto del firmware.

Izquierda / derechaFuera del menu cambia de pagina. Dentro del menu vuelve o confirma segun la vista.
Boton MENUAbre el menu en paginas normales. En menu ejecuta la opcion seleccionada.
